# CPU 사용률 및 극대값 기반 급상승 구간 분석 리포트

## 1. 분석 개요

본 리포트는 `monitor.sh`로 수집한 CPU 사용률 로그를 기반으로, 프로세스의 CPU 사용률 변화와 순간적인 증가 구간을 분석한 결과이다.

CPU 사용률 자체뿐 아니라, 연속된 두 샘플 사이의 CPU 변화량을 시간 차이로 나눈 `Delta CPU / Delta t` 값을 계산하였다. 이후 어떤 샘플이 직전 샘플보다 크고 다음 샘플보다 크거나 같은 극대값으로 확인되면, 그 샘플 직전 구간을 급상승 구간으로 판단하였다.

## 2. 분석 방법

- 입력 로그에서 timestamp와 CPU 사용률 값을 추출하였다.
- 각 샘플 사이의 CPU 변화량을 계산하였다.
- 변화량을 시간 간격으로 나누어 `Delta CPU / Delta t (%/s)`를 계산하였다.
- `CPU[i] > CPU[i-1]` 이고 `CPU[i] >= CPU[i+1]`이면 `CPU[i]`를 극대값으로 판단하였다.
- 극대값이 확인되면 `CPU[i-1] -> CPU[i]` 구간을 급상승 구간으로 표시하였다.
